# نصوص Canva جاهزة — ريلز · بانرز · بوستات صور

انسخ من هنا (VS Code / Notepad مش التيرمينال). كل بلوك = نص جاهز تحطه على التصميم.
القاعدة: **سطر كبير واحد + سطر صغير واحد + زرار/CTA** — التصميم اللي فيه كلام كتير محدش بيقراه.

---

## 1 · خطافات الريلز (أول ٣ ثواني — نص كبير على الفيديو)

```
مين قال التمرين محتاج جيم؟
```
```
٢٠ دقيقة في اليوم… والنتيجة بتتكلم
```
```
الكشري ليه سعرات قد إيه؟ 👀
```
```
جسمك مش محتاج اشتراك جيم بـ١٥٠٠ جنيه
```
```
السلسلة بتاعتك وصلت كام يوم؟ 🔥
```
```
أصعب حاجة في التمرين؟ إنك تبدأ. وإحنا حلّيناها.
```
```
اتحداك تعمل التمرين ده معايا دلوقتي
```
```
الفرق بين اللي بيكمل واللي بيقف: حد بيشدّه
```

## 2 · قفلات الريلز (آخر ثانيتين + الكابشن)

```
التطبيق مجاني ١٠٠٪ — لينك التحميل في البايو 📲
```
```
جرّبها النهاردة… وسيب النتيجة تتكلم. PULSE على Google Play
```
```
تقدر تعملها ٢٠ يوم؟ اكتب «أقدر» في الكومنتات 💪
```
```
شير للي محتاج يبدأ معاك 🤝
```

## 3 · بانرات التسجيل (Headline كبير + سطر صغير)

**بانر ١ — العرض الأساسي:**
```
جيم في موبايلك 🔥
تمارين بالفيديو + سعرات الأكل المصري + تحديات بجوايز — ببلاش
```

**بانر ٢ — ضد الاشتراكات:**
```
من غير فيزا. من غير اشتراك. من غير أعذار.
كوتشك وصحابك — معاك في أي وقت
```

**بانر ٣ — الأكل المصري:**
```
أول تطبيق بيحسب الكشري والفول والطعمية 🍽
قول أكلت إيه… وإحنا نحسب
```

**بانر ٤ — السوشيال:**
```
مش هتكمل لوحدك 🤝
أصحاب وتحديات ودوري أسبوعي بيشدوك كل يوم
```

**CTA موحد تحت أي بانر:**
```
حمّله مجاناً من Google Play 📲
```

## 4 · بوستات صور (اقتباسات تحفيزية — للانتشار والشير)

```
الجسم اللي بتحلم بيه… محتاج اليوم اللي بتأجله
```
```
مش لازم تكون قوي عشان تبدأ. لازم تبدأ عشان تكون قوي
```
```
٢٠ يوم التزام أحسن من سنة نوايا
```
```
كل تمرينة بتخلصها… وعد بتوفيه لنفسك
```
(حط لوجو PULSE صغير في الركن — من غير لينك، البوستات دي للشير)

## 5 · طقم تحدي سبتمبر 💸

**أ) بانر الإعلان الرئيسي:**
```
تحدي سبتمبر 🏆
١,٠٠٠ جنيه جوايز كاش حقيقية
```
سطر صغير:
```
اتمرن ٢٠ يوم خلال سبتمبر — والفلوس فودافون كاش
```

**ب) بوست تفاصيل الجوايز (تصميم بوديوم):**
```
🥇 الأول: ٥٠٠ جنيه
🥈 التاني: ٢٠٠ جنيه
🥉 التالت: ٢٠٠ جنيه
🎟 قرعة ١٠٠ جنيه لكل اللي يكمّلوا
```
سطر تحت:
```
مفيش حظ… فيه التزام. التحدي يبدأ ١ سبتمبر
```

**ج) عدّاد قبل البداية (ستوري/بوست يوم ٣٠–٣١ أغسطس):**
```
باقي يومين ⏳
جهّز نفسك… ٢٠ يوم تمرين بينك وبين ٥٠٠ جنيه
```

**د) يوم الانطلاق (١ سبتمبر):**
```
التحدي بدأ 🔥
ادخل دلوقتي — كل يوم بيتحسب
```

**هـ) بوست الليدربورد الأسبوعي:**
```
أسبوع ١ خلص 👀
دول اللي في الصدارة… تقدر تعديهم؟
```

**و) آخر أيام (٢٧–٣٠ سبتمبر):**
```
⏳ آخر ٣ أيام
كمّل الـ٢٠ يوم — القرعة والبوديوم لسه مفتوحين
```

**ز) بوست الفايزين (١ أكتوبر — مع سكرين التحويلات):**
```
وعدنا… ووفينا 🤝
دي تحويلات جوايز تحدي سبتمبر — فلوس حقيقية لناس التزمت
```
سطر تحت:
```
تحدي أكتوبر جاي أقوى… تابعنا عشان تلحقه
```

## 6 · قواعد التصميم السريعة (لأي تمبلت في Canva)
- ألوان البراند: برتقالي `#F97316` على أبيض، أو أبيض على غامق `#161513`.
- خط عربي جريء (Cairo / Tajawal Bold) — العنوان مايزيدش عن ٨ كلمات.
- لوجو PULSE في نفس الركن في كل التصميمات (بيبني تعرّف على البراند).
- مقاس ريلز/ستوري: 1080×1920 · بوست مربع: 1080×1080 · بانر فيسبوك: 1200×630.
- صورة واحدة قوية (ناس حقيقية بتتمرن) أحسن من ٥ عناصر متزاحمة.
