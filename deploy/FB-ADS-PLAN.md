# خطة إعلانات فيسبوك — حملتين

انسخ من VS Code / Notepad. قبل أي حاجة: اتأكد إن الـ Pixel شغال (القسم صفر).

---

## 0 · قبل ما تدفع جنيه واحد (مرة واحدة)

1. **Meta Pixel**: من Events Manager خد الـ Pixel ID وحطه في `apps/web/.env` سطر
   `VITE_FB_PIXEL_ID=...` ثم اعمل deploy. الموقع بيبعت لوحده حدثين مهمين:
   - `CompleteRegistration` لما حد يسجل ✅ (ده اللي الحملة الأولى هتتحسّن عليه)
   - PageView تلقائي
2. **اختبر**: افتح الموقع → سجّل حساب تجريبي → شوف الحدث ظهر في Events Manager → Test events.
3. **قاعدة UTM**: كل إعلان لينكه فيه `?utm_source=facebook&utm_medium=cpc&utm_campaign=<اسم>` — كده لوحة الأدمن بتوريك مين جاب مين.

## 1 · الحملة الأولى: تسجيلات (الأهم — 70٪ من الميزانية)

| إعداد | القيمة |
|---|---|
| الهدف (Objective) | **Sales / Conversions** — Conversion event: `CompleteRegistration` |
| الوجهة | `https://pulse.geddo.online/?utm_source=facebook&utm_medium=cpc&utm_campaign=reg-sept` |
| الجمهور | مصر · ١٨–٣٥ · كل الأجهزة (أندرويد أولوية) |
| Ad Sets (اتنين للاختبار) | ① Broad من غير اهتمامات (سيب الخوارزمية) · ② اهتمامات: Gym, Fitness, Weight loss, دايت |
| الميزانية | ٢٠٠–٣٠٠ ج/يوم للحملة كلها · أسبوع اختبار |
| الإعلانات | ٣ ريلز 9:16 مختلفة الخطاف (من CANVA-COPY) لكل Ad Set |

**الكرياتيف الفائز غالباً**: ريل حقيقي من التطبيق (شاشة التمرين أو حساب سعرات الكشري) + خطاف
«جيم في موبايلك — ببلاش من غير اشتراك» + CTA «سجّل مجاناً».

**زاوية تحدي سبتمبر** (أقوى إعلان دلوقتي):
```
٩٠٠ جنيه جوايز كاش 💸 اتمرن ٢٠ يوم في سبتمبر واكسب.
التطبيق مجاني ١٠٠٪ — سجّل وادخل التحدي قبل ما يفوتك.
```

**قواعد القتل والتثبيت (بعد ٣–٤ أيام):**
- إعلان تكلفة التسجيل فيه أعلى من الضعف من أحسن إعلان → اقفله.
- الـ Ad Set الأحسن ياخد ميزانية الأضعف.
- متلمسش إعلان شغال كويس (بتصفّر التعلّم).
- هدف واقعي في مصر: تسجيل بـ **٥–١٥ ج**. لو فوق ٢٥ ج بعد أسبوع → غيّر الكرياتيف مش الجمهور.

## 2 · الحملة التانية: تريند وترافيك (٣٠٪ — بتبني جمهور الريتارجت)

الهدف الحقيقي منها: تملى «حوض» ناس اتفاعلت — نستهدفهم تاني بإعلان التسجيل بسعر أرخص.

| إعداد | القيمة |
|---|---|
| الهدف | **Engagement → Video views** (ThruPlay) — أرخص وصول ممكن |
| المحتوى | أحسن ٢–٣ ريلز أورجانيك عندك (اللي جابوا مشاهدات) — Boost من Ads Manager مش زرار Boost |
| الجمهور | مصر ١٨–٣٥ Broad |
| الميزانية | ٥٠–١٠٠ ج/يوم مستمرة |

**بعد أسبوعين — حملة الريتارجت (جوهرة الخطة):**
- اعمل Custom Audience: «شاهد ٥٠٪ من أي فيديو خلال ٣٠ يوم» + «تفاعل مع الصفحة/انستجرام».
- استهدفهم بحملة تسجيلات منفصلة (`utm_campaign=reg-retarget`) — دول أرخص تسجيلات هتجيبها
  لأنهم شافوك قبل كده.

## 3 · القياس كل جمعة (١٠ دقايق)

| مصدر | تشوف إيه |
|---|---|
| Ads Manager | تكلفة التسجيل (CPR) لكل إعلان · CTR (كويس فوق 1.5٪) |
| Admin → Analytics | فانل facebook: كام وصل → سجّل → اتفعّل (الأرقام الحقيقية مش أرقام فيسبوك) |
| Play Console | التنزيلات (بتاخر يوم-يومين) |
| Analytics → Platforms | نسبة مستخدمي تطبيق Play بتزيد؟ |

القرار الأسبوعي واحد: **وقّف الأغلى، زوّد الأرخص، جرّب خطاف جديد واحد.**

## 4 · ممنوعات (بتترفض أو بتضرب الحساب)
- «اخسر ١٠ كيلو في أسبوعين» أو أي وعد نتيجة جسدية محددة — فيسبوك بيرفض إعلانات الوزن المبالغة، والقاعدة عندنا أصلاً وعود صادقة.
- صور قبل/بعد — مخالفة صريحة لسياسة الإعلانات الصحية.
- Engagement bait («اعمل لايك لو…») — بيتخفض توزيعه.
- ذكر منافسين — قاعدة البراند.
- لينك من غير UTM — مجهود ضايع مش بيتقاس.

## 5 · التطور الطبيعي بعد شهر
1. الفائز من حملة التسجيلات ياخد 80٪ وتحوّلها **Advantage+** (أتمتة كاملة).
2. جرّب نفس الفائز على **إنستجرام Placement فقط** — أحياناً أرخص.
3. لما iOS ينزل: نفس الحملات تشتغل للآيفون تلقائياً (نفس الموقع، نفس البيكسل).
4. فكّر في **Google App Campaign** لتنزيلات Play مباشرة — غالباً أرخص تنزيل من فيسبوك (خطوة منفصلة لما تجهز).
